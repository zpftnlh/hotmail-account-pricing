## @hotmail.com 现在到底是什么

Hotmail 作为独立邮箱服务多年前就停了。今天你看到的 @hotmail.com 只是 Outlook.com 上的一个地址后缀，登录页面、后台、底层账号都是同一套微软账号。号商把“Hotmail 账号”和“Outlook 账号”分成两个类目，区别主要在地址长什么样，背后是同一类东西。

这个后缀还有人买，是因为部分海外平台的注册流程对老域名有隐性偏好，@hotmail.com 看起来更像早年注册的真人号。用途明确的话，为这个后缀多付一点是合理的；不明确的话，同价位的 Outlook 号没任何劣势。

## 为什么有的号贵三倍

四个变量在推价格，看懂就能自己对号。

**有没有 token。** 微软现在对“只凭密码的第三方客户端”卡得很紧，程序要取信得用 OAuth2 refresh token 加签发它的 client ID，交给邮件工具后走 Microsoft Graph 打开邮箱。商品标题写 “OAuth2 Refresh Token | Graph API Ready” 的就是这类，报价通常比同存活时长的纯密码号高一档。只在浏览器里看收件箱，密码就够用，token 是给工具用的，别为用不上的能力付钱。

**活了多久。** 注册 20 天和存活 12–36 个月，在风控眼里的权重完全不同。老号历史长、行为记录多，被要求二次验证的概率低一些，这是它贵的主因。

**有没有恢复邮箱。** 带辅助邮箱的号多一条找回路径，同时说明这个号被人动过、不是原生状态。原生未动的号更“干净”，价格也更高。

**Skip 7 Days 这类标记。** 部分商品标题带这个后缀，同配置下报价明显更低。它跳过的是哪一段质保、跳过之后出问题谁负责，下单前直接问客服，别自己猜。
